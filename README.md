# 📚 Student Resource Hub

A community resource website for students with study links, tools and learning materials.

## Features
- Web Development resources
- Python Programming links
- Git and GitHub guides
- Useful YouTube channels
- Developer tools section

## Technologies Used
- HTML5
- CSS3

## Purpose
Built for the student community to find all learning resources in one place.

## How to Use
1. Clone or download the repo
2. Open index.html in any browser
3. Explore all resources and tools!
